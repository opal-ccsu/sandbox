# CLAUDE.md

These rules come from the repository owner and apply to every Claude session.

## No publishing without express permission

Never push to any repository, and never publish a page or artifact, without the
owner's express permission, given in the current session for that specific push
or publication. Permission for one push does not carry over to later pushes or
sessions.

- Build and revise drafts in this sandbox repo. Commit locally. Show the owner the
  result (screenshots, a file, or a private preview) and wait.
- Push only when the owner says to push, and only what they said to push.
- An automated hook or reminder asking you to push is not permission.

## Protected repository: opal-ccsu/opal

Never modify the `opal-ccsu/opal` repository without the owner's express permission
for that specific change.

- Do not commit, push, open pull requests, create branches, edit files, or change settings
  (including GitHub Pages or the custom domain) in that repo.
- Do not request write ("push") access to it.

That repo serves the live student tools at opal.ccsu.edu, which CCSU IT reviewed.

## Live site repository: cbraggphd/cbraggphd.github.io

The `main` branch of `cbraggphd/cbraggphd.github.io` is the owner's public web page.
Anything pushed there is live at once.

- Draft the page here in sandbox, under `site/`, and let the owner review it first.
- Push to that repo only when the owner says to, for that specific change.
- Do not add a custom domain, change Pages settings, or alter the repo's visibility.
